shorts-auto

shorts-auto is a personal, non-commercial-software tool used by a single creator to publish short explainer videos to the creator's own YouTube channels (특이점한걸음, 뜨는이유).

The tool prepares a video on the creator's own computer. After the creator manually reviews and approves the video, the tool uploads it to the creator's own YouTube channel using the YouTube Data API (scope: youtube.upload). It is not offered to other users.

개인 크리에이터 한 명이 자신의 유튜브 채널에 직접 만든 쇼츠를 올리기 위해 쓰는 개인용 도구입니다. 영상은 사람이 검수·승인한 뒤에만 YouTube Data API로 본인 채널에 업로드됩니다. 다른 사용자에게 제공하지 않습니다.
